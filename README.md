# Diabetes Prediction Using Machine Learning

## 📌 Project Overview

This project implements a machine learning model to predict whether a patient is likely to have diabetes based on several medical attributes.

The dataset contains **768 records** with **8 input features** related to patient health information. The data is preprocessed using feature standardization and then divided into training and testing datasets.

A **Support Vector Machine (SVM)** classifier with a linear kernel is trained to classify patients as either diabetic or non-diabetic.

## 🎯 Objective

The main objective of this project is to build a machine learning model that can analyze medical attributes and predict whether a patient is:

* **0 — Non-Diabetic**
* **1 — Diabetic**

## 📊 Dataset

The dataset contains **768 rows and 9 columns**, including the target variable.

### Input Features

* **Pregnancies** — Number of pregnancies
* **Glucose** — Plasma glucose concentration
* **BloodPressure** — Diastolic blood pressure
* **SkinThickness** — Triceps skinfold thickness
* **Insulin** — Serum insulin level
* **BMI** — Body Mass Index
* **DiabetesPedigreeFunction** — Diabetes pedigree function
* **Age** — Patient age

### Target

* **Outcome**

  * `0` = Non-Diabetic
  * `1` = Diabetic

The dataset contains:

* **500 Non-Diabetic cases**
* **268 Diabetic cases**

## ⚙️ Project Workflow

The project follows the following machine learning pipeline:

1. Import required Python libraries
2. Load the diabetes dataset
3. Perform basic data analysis
4. Separate features and target variable
5. Standardize the input features using `StandardScaler`
6. Split the dataset into training and testing sets
7. Train a Support Vector Machine classifier
8. Evaluate the model using accuracy score
9. Build a predictive system for new patient data

## 🔧 Data Preprocessing

Since medical features such as glucose, BMI, insulin, and age have different numerical ranges, the features are standardized using:

```python
StandardScaler()
```

Standardization helps bring the features onto a similar scale before training the SVM model.

## 🧠 Machine Learning Model

The project uses a **Support Vector Machine (SVM)** classifier with a linear kernel.

```python
classifier = svm.SVC(kernel='linear')
```

The dataset is divided into:

* **80% Training Data**
* **20% Testing Data**

Stratified splitting is used to preserve the proportion of diabetic and non-diabetic samples in both datasets.

## 📈 Model Performance

The trained SVM model achieved:

| Dataset       |   Accuracy |
| ------------- | ---------: |
| Training Data | **78.66%** |
| Testing Data  | **77.27%** |

The results show that the model maintains similar performance on both training and testing data.

## 🔮 Predictive System

The project also contains a predictive system that allows new patient medical information to be supplied to the trained model.

The input data is first standardized using the same scaler used during training and then passed to the SVM classifier.

The system returns one of two predictions:

```text
Patient is Non-Diabetic
```

or

```text
Patient is Diabetic
```
